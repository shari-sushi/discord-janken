# 実行計画書: user-common-message コマンド実装

## 概要

誰でも編集できる共有メッセージを投稿するDiscordコマンドを実装する。

## 背景・目的

「メッセージを複数人で編集できるコマンド」の実装。
チームで共有したいテキスト（ルール、メモ、アナウンス等）を投稿し、
誰でも編集ボタンから内容を更新できる。

## 機能仕様

### コマンド

```text
/user-common-message
```

### 操作フロー

```text
[ユーザーがコマンド実行]
  └→ モーダルを表示（textarea で長文入力可能）

[モーダルでテキストを入力して送信]
  └→ チャンネルにメッセージ投稿（入力テキスト + 「編集」ボタン）
  └→ 送信者にのみ「投稿しました」を ephemeral で表示

[誰かが「編集」ボタンをクリック]
  └→ interaction.message.content から現在のテキストを取得
  - 他人が編集できないように編集ボタンをdisabledで「編集中」のにする
  - disabledのままフリーズしないように、「編集中を強制終了」ボタンを表示させる
  └→ モーダルを表示（textarea に現在のテキストがデフォルト値としてセット済み）

[モーダルでテキストを編集して送信]
  └→ interaction から message_id / channel_id を取り出す
  └→ editDiscordMessage() でメッセージを上書き（編集ボタン付きのまま）
  └→ 送信者にのみ「編集しました」を ephemeral で表示
  - ボタンを「編集」に戻す

[「編集中を強制終了」ボタンをクリック]
  - ボタンを「編集」に戻す
```

## 技術設計

### custom_id 設計

| 用途 | custom_id | 備考 |
| --- | --- | --- |
| 初回投稿用モーダル | `submit-new-common-message` | - |
| 編集ボタン | `open-modal-edit-common-message` | message_id はインタラクション時に取得 |
| 編集用モーダル | `submit-common-message?message_id={id}` | message_id のみ |
| 強制終了ボタン | `force-end-editing-common-message` | シンプル |

※channel_id は interaction.channel_id から取得

### モーダル仕様

#### 初回投稿用モーダル

- Text Input: style 2 (Paragraph / 複数行)
- `value` フィールド：空（初回なので）
- `placeholder`: 「メッセージを入力してください」
- 文字数上限: 2000文字（Discord メッセージ content の上限に合わせる）

#### 編集用モーダル

- Text Input: style 2 (Paragraph / 複数行)
- `value` フィールドに現在のメッセージ内容をセット
- 文字数上限: 2000文字（Discord メッセージ content の上限に合わせる）

#### 共通仕様

- discordの課金機能で2000文字を超えられるが、それはこっちのbotにも課金してもらう場合に解除する。今のところ実装予定はない。

### メッセージ編集方法

`editDiscordMessage(channelId, messageId, newContent, components)` を使用。
`components` に編集ボタンを渡すことでボタンが消えないようにする。

### レスポンス設計

| タイミング | レスポンス type | 内容 |
| --- | --- | --- |
| コマンド実行 | `9` (MODAL) | 初回投稿用モーダル表示 |
| 初回モーダル送信 | `4` (CHANNEL_MESSAGE_WITH_SOURCE) | テキスト + 編集ボタン |
| 初回投稿完了 | `4` + `flags: 64` | 「投稿しました」ephemeral |
| 編集ボタン押下 | `9` (MODAL) | 編集モーダル表示 |
| 編集モーダル送信 | `4` + `flags: 64` | 「編集しました」ephemeral |
| 強制終了ボタン押下 | `4` + `flags: 64` | 「編集を強制終了しました」ephemeral |

## 実装ファイル一覧

### `app/util/commands.ts`

**実装内容**: `CLIENT_ACTIONS.USER` に以下の定数を実装

- `SUBMIT_NEW_COMMON_MESSAGE`: 初回投稿用モーダルのcustom_id (`"submit-new-common-message"`)
- `OPEN_MODAL_EDIT_COMMON_MESSAGE`: 編集ボタンのcustom_id (`"open-modal-edit-common-message"`)
- `SUBMIT_COMMON_MESSAGE`: 編集用モーダルのcustom_id (`"submit-common-message"`)
- `FORCE_END_EDITING_COMMON_MESSAGE`: 強制終了ボタンのcustom_id (`"force-end-editing-common-message"`)

### `app/api/discord/register-commands.ts`

**実装内容**: Discordコマンド定義を実装

```typescript
const commonMessage: DiscordBotCommand = {
  name: COMMANDS.USER.COMMON_MESSAGE,
  description: "みんなで編集できる共有メッセージを投稿します",
  options: [], // オプションなし
}
```

### `app/api/discord/application-command/user/commonMessage.ts`

**実装内容**: 5つのハンドラー関数と1つのヘルパー関数を実装

#### 1. `createEditButton(disabled: boolean, includeForceEnd: boolean): ActionRow[]`

編集ボタンのコンポーネントを作成するヘルパー関数。

- **引数**:
  - `disabled`: ボタンを無効化するか
  - `includeForceEnd`: 「編集中を強制終了」ボタンを含めるか
- **処理**:
  - 編集ボタン（PRIMARY、custom_id: `CLIENT_ACTIONS.USER.OPEN_MODAL_EDIT_COMMON_MESSAGE`）を作成
  - `disabled` が `true` の場合、ラベルを「編集中...」にして無効化
  - `includeForceEnd` が `true` の場合、強制終了ボタン（DANGER、custom_id: `CLIENT_ACTIONS.USER.FORCE_END_EDITING_COMMON_MESSAGE`）を追加
- **戻り値**: `ActionRow[]` 配列

#### 2. `commonMessageCommand()`

コマンド実行時に初回投稿用モーダルを表示する。

- **引数**: なし
- **処理**:
  - モーダルコンポーネントを作成
    - `INPUT_TEXT` (PARAGRAPH スタイル)
    - `custom_id`: `"common_message_content"`
    - `label`: `"メッセージ内容"`
    - `max_length`: `2000`
    - `placeholder`: `"メッセージを入力してください"`
  - レスポンスタイプ `9` (MODAL) を返す
  - `custom_id`: `CLIENT_ACTIONS.USER.SUBMIT_NEW_COMMON_MESSAGE`
  - `title`: `"共有メッセージを投稿"`
- **戻り値**: `NextResponse` (モーダル表示)

#### 3. `handleSubmitNewCommonMessage(interaction: any)`

初回投稿用モーダル送信処理。

- **引数**: `interaction` (Discord インタラクションオブジェクト)
- **処理**:
  1. `interaction.channel_id` からチャンネルIDを取得
  2. `interaction.data.components` からテキスト内容を取得（`custom_id` が `"common_message_content"` のものを検索）
  3. バリデーション:
     - チャンネルIDが取得できない → エラー (ephemeral)
     - 文字数が2000文字超 → エラー (ephemeral)
     - 空文字 → エラー (ephemeral)
  4. `sendDiscordMessage(channelId, content, createEditButton(false, false))` でメッセージ投稿
  5. 成功時: 「✅ 投稿しました」(ephemeral)
  6. 失敗時: エラーメッセージ (ephemeral)
- **戻り値**: `NextResponse` (ephemeral メッセージ)

#### 4. `handleOpenModalEditCommonMessage(interaction: any)`

編集ボタン押下時の処理。

- **引数**: `interaction` (Discord インタラクションオブジェクト)
- **処理**:
  1. `interaction.message.id` からメッセージIDを取得
  2. `interaction.channel_id` からチャンネルIDを取得
  3. `interaction.message.content` から現在のテキストを取得
  4. 文字数が4000文字超の場合 → エラー (ephemeral)
  5. `editDiscordMessage()` でボタンを無効化（`createEditButton(true, true)`）
  6. モーダルを表示
     - `INPUT_TEXT` (PARAGRAPH スタイル)
     - `custom_id`: `"common_message_content"`
     - `value`: 現在のテキスト
     - `max_length`: `2000`
  7. モーダルの `custom_id`: `CLIENT_ACTIONS.USER.SUBMIT_COMMON_MESSAGE + "?message_id=" + messageId`
- **戻り値**: `NextResponse` (モーダル表示)

#### 5. `handleSubmitCommonMessage(interaction: any)`

編集用モーダル送信処理。

- **引数**: `interaction` (Discord インタラクションオブジェクト)
- **処理**:
  1. `interaction.data.custom_id` から `message_id` をクエリパラメータとして取得
  2. `interaction.channel_id` からチャンネルIDを取得
  3. `interaction.data.components` から新しいテキストを取得
  4. バリデーション:
     - `message_id` または `channel_id` が取得できない → エラー (ephemeral)
     - 文字数が2000文字超 → エラー (ephemeral)
  5. `editDiscordMessage(channelId, messageId, newContent, createEditButton(false, false))` でメッセージ更新
  6. 成功時: 「✅ 編集しました」(ephemeral)
  7. 失敗時: エラーメッセージ (ephemeral)
- **戻り値**: `NextResponse` (ephemeral メッセージ)

#### 6. `handleForceEndEditingCommonMessage(interaction: any)`

編集中を強制終了する処理。

- **引数**: `interaction` (Discord インタラクションオブジェクト)
- **処理**:
  1. `interaction.message.id` からメッセージIDを取得
  2. `interaction.channel_id` からチャンネルIDを取得
  3. `interaction.message.content` から現在のテキストを取得
  4. バリデーション:
     - `message_id` または `channel_id` が取得できない → エラー (ephemeral)
  5. `editDiscordMessage(channelId, messageId, currentContent, createEditButton(false, false))` でボタンを通常の「編集」ボタンに戻す
  6. 成功時: 「✅ 編集を強制終了しました」(ephemeral)
  7. 失敗時: エラーメッセージ (ephemeral)
- **戻り値**: `NextResponse` (ephemeral メッセージ)

### `app/api/discord/route.ts`

**実装内容**: ルーティングを実装

1. **import文**: `commonMessageCommand`, `handleSubmitNewCommonMessage`, `handleOpenModalEditCommonMessage`, `handleSubmitCommonMessage`, `handleForceEndEditingCommonMessage` をimport
2. **APPLICATION_COMMAND**: `COMMANDS.USER.COMMON_MESSAGE` → `commonMessageCommand()` を呼び出し
3. **MESSAGE_COMPONENT**: `CLIENT_ACTIONS.USER.OPEN_MODAL_EDIT_COMMON_MESSAGE` → `handleOpenModalEditCommonMessage(interaction)` を呼び出し
4. **MESSAGE_COMPONENT**: `CLIENT_ACTIONS.USER.FORCE_END_EDITING_COMMON_MESSAGE` → `handleForceEndEditingCommonMessage(interaction)` を呼び出し
5. **MODAL_SUBMIT**: `CLIENT_ACTIONS.USER.SUBMIT_NEW_COMMON_MESSAGE` → `handleSubmitNewCommonMessage(interaction)` を呼び出し（完全一致）
6. **MODAL_SUBMIT**: `CLIENT_ACTIONS.USER.SUBMIT_COMMON_MESSAGE` → `handleSubmitCommonMessage(interaction)` を呼び出し（前方一致）

## 実装手順

1. `commands.ts` に4つのcustom_id定数を実装
2. `register-commands.ts` に `commonMessage` コマンド定義を実装
3. `commonMessage.ts` にヘルパー関数と5つのハンドラー関数を実装
4. `route.ts` にimportと6箇所のルーティングを実装
5. `npm run lint` と `npx tsc --noEmit` でエラーがないことを確認

## 注意事項

- **ボタン維持**: `editDiscordMessage()` に `components` を渡さないと編集ボタンが消える
- **文字数バリデーション**: テキストが2000文字超の場合は ephemeral エラーと、discordおよびdiscord botに課金すると文字数制限を緩められる旨を表示する
- **3秒制限**: `editDiscordMessage()` は軽量なREST呼び出しのため問題なし
- **Redis不要**: `interaction.message.content` から直接現在のテキストを取得できるため追加ストレージ不要
