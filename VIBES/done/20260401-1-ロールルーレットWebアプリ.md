# ロールルーレット Webアプリ

## 目的・背景

Discord Bot版のロールルーレットが Rate Limit 問題で安定しないため、
ブラウザ上で完結する単体ツールとして実装する。
1人がメンバーと希望ロールを入力して抽選するシンプルな用途を想定。

## 実装計画

### 1. ロジックファイルの移動

`app/domains/lol/_server/roleRoulette.ts` はサーバー依存（DB・外部API呼び出し）がなく純粋なロジックのみ。
クライアントでも使えるよう `_server/` から外に移動する。

- `app/domains/lol/_server/roleRoulette.ts` → `app/domains/lol/roleRoulette.ts`
- importパス更新:
  - `app/api/discord/command/lol/roleRoulette.ts`
  - `app/domains/lol/_server/roleRoulette.test.ts`（あれば）

### 2. ページ作成

`app/lol/role-roulette/page.tsx`（`"use client"`）

#### UI構成

```txt
[参加者入力]
textarea（1行1人）

[参加者リスト] ← textarea の内容を行分割してリアルタイム生成
| 名前 | TOP | JG | MID | ADC | SUP | FILL |
| ---- | --- | -- | --- | --- | --- | ---- |
| ...  | □  | □  |  □  |  □  |  □  |  □   |

[抽選開始ボタン]

[結果表示エリア]
TOP: 〇〇
JG:  〇〇
...
休憩: 〇〇, 〇〇（5人超の場合）
```

#### 状態管理

| state | 型 | 説明 |
| --- | --- | --- |
| `namesText` | `string` | textarea の生テキスト |
| `roleSelections` | `Record<string, Set<RoleKey \| "FILL">>` | 名前 → 選択ロール |
| `result` | `RouletteResult \| null` | 抽選結果 |

#### ロジック

- `runRoleRoulette` にはユーザーIDを渡す設計のため、Web版では名前をそのままIDとして渡す
- Bot除外用 `botId` は空文字列 `""` を渡す（名前が空文字になることはないため問題なし）
- textarea の行変更でプレイヤーが増減した際、既存のチェック状態はできる限り維持する

### 3. 認証

認証なし。URLを知っていれば誰でも使える。

## 技術選定

- フレームワーク: Next.js App Router（既存に合わせる）
- スタイリング: Tailwind CSS（既存に合わせる）
- 状態管理: `useState`（シンプルなため外部ライブラリ不要）
- ロジック: 既存の `runRoleRoulette` を流用
