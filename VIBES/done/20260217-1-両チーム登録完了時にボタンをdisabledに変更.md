# 両チーム登録完了時にボタンをdisabledに変更

## 目的

両チームの登録が完了して結果発表が行われた後、「ブルーサイド」「レッドサイド」ボタンを disabled にすることで、**結果発表後に再登録できないようにする**。

## 設計方針

- handlerである `route.ts` 側で以下の2つの関数を呼び出すようにすることで、責務を分け可読性を上げる
  - 既存 `handleRegisterTeam`：メインのロジックとDB管理を行いレスポンスのメッセージを返す
  - 新規 `disableRegisterButtonsMessage`：メッセージの編集をdiscordへリクエストする
- `handleRegisterTeam`の戻り値を `{ response: NextResponse; isBothTeamsRegistered: boolean }` に変更し、**route.ts** でメッセージ編集を判断・実行する
- `message_id` / `channel_id` の取得方法:
  - **MODAL_SUBMIT（REGISTER_RED/BLUE_TEAM）**: modal の `custom_id` にクエリパラメータとして埋め込む
    - 例: `"register-red-team?message_id=1234&channel_id=5678"`
    - ボタンクリック時（MESSAGE_COMPONENT）に `interaction.message.id` と `interaction.channel_id` が取得可能なため、`handleOpenModalProtectRole` に引数として渡す

## 変更ファイル一覧

| ファイル | 変更概要 |
| --- | --- |
| `app/api/discord/application-command/newProtect.ts` | `handleRegisterTeam` 戻り値型変更、`handleOpenModalProtectRole` に引数追加 |
| `app/api/discord/route.ts` | modal ハンドラーへの引数追加、戻り値フラグを見てメッセージ編集、`disableRegisterButtonsMessage` ヘルパー追加 |
| `app/util/protectMessageComponents.ts` | `isDisabledTeamButtons`パラメータ追加 |

## ステップ

### ステップ1: `newProtect.ts` の `handleOpenModalProtectRole` 変更

引数 `messageId: string` と `channelId: string` を追加し、modal の `custom_id` に埋め込む。

```ts
// Before
export const handleOpenModalProtectRole = async (teamSide: TeamSide, matchId: string)

// After
export const handleOpenModalProtectRole = async (teamSide: TeamSide, matchId: string, messageId: string, channelId: string)
```

```ts
// modal custom_id への埋め込み（Before）
custom_id: isBlue ? CLIENT_ACTIONS.REGISTER_BLUE_TEAM : CLIENT_ACTIONS.REGISTER_RED_TEAM,

// After
custom_id: isBlue
  ? `${CLIENT_ACTIONS.REGISTER_BLUE_TEAM}?message_id=${messageId}&channel_id=${channelId}`
  : `${CLIENT_ACTIONS.REGISTER_RED_TEAM}?message_id=${messageId}&channel_id=${channelId}`,
```

### ステップ2: `newProtect.ts` の `handleRegisterTeam` 戻り値型変更

すべての return を `{ response: NextResponse; isBothTeamsRegistered: boolean }` 形式に変更。

- エラー系 / 片方完了: `isBothTeamsRegistered: false`
- 両チーム完了（`createCompletionEmbed` を返す箇所）: `isBothTeamsRegistered: true`

### ステップ3: `route.ts` に `disableRegisterButtonsMessage` を追加

Discord REST API（PATCH）を呼び出して、ボタンを disabled にし、メッセージ本文を更新するヘルパー。

```ts
async function disableRegisterButtonsMessage(messageId: string, channelId: string, matchId: string) {
  try {
    await fetch(`https://discord.com/api/v10/channels/${channelId}/messages/${messageId}`, {
      method: "PATCH",
      headers: {
        Authorization: `Bot ${process.env.DISCORD_BOT_TOKEN}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        content: "両チーム入力完了し、結果が発表されました",
        components: createProtectComponents(matchId, true),
      }),
    })
  } catch (e) {
    console.error("Failed to disable register buttons:", e)
  }
}
```

 `app/util/protectMessageComponents.ts` の `createProtectComponents`に `isDisabledTeamButtons`パラメータ追加をdefault: false のオプショナルで追加し、「ブルーサイド」「レッドサイド」のボタンのdisabledフラグに使用する。

### ステップ4: `route.ts` の MESSAGE_COMPONENT ハンドラー変更

`OPEN_MODAL_RED/BLUE_TEAM_REGISTER` のケースで `interaction.message?.id` と `interaction.channel_id` を渡す。

```ts
case CLIENT_ACTIONS.OPEN_MODAL_RED_TEAM_REGISTER:
  return handleOpenModalProtectRole("red_team", matchId, interaction.message?.id ?? "", interaction.channel_id ?? "")

case CLIENT_ACTIONS.OPEN_MODAL_BLUE_TEAM_REGISTER:
  return handleOpenModalProtectRole("blue_team", matchId, interaction.message?.id ?? "", interaction.channel_id ?? "")
```

### ステップ5: `route.ts` の MODAL_SUBMIT ハンドラー変更

- `customId.split("?")[0]` で action 部分を完全一致チェック（すでに `modalActionId` として実装済み）
- `custom_id` から `message_id` / `channel_id` をパース
- `handleRegisterTeam` の戻り値フラグを見てメッセージ編集

```ts
// message_id / channel_id をモーダルの custom_id からパース
const modalParams = new URLSearchParams(customId.split("?")[1] || "")
const messageId = modalParams.get("message_id") ?? ""
const channelId = modalParams.get("channel_id") ?? ""

if (modalActionId === CLIENT_ACTIONS.REGISTER_RED_TEAM) {
  const { response, isBothTeamsRegistered } = await handleRegisterTeam("red_team", matchId, interaction.data)
  if (isBothTeamsRegistered && messageId && channelId) {
    await disableRegisterButtonsMessage(messageId, channelId, matchId)
  }
  return response
}

if (modalActionId === CLIENT_ACTIONS.REGISTER_BLUE_TEAM) {
  const { response, isBothTeamsRegistered } = await handleRegisterTeam("blue_team", matchId, interaction.data)
  if (isBothTeamsRegistered && messageId && channelId) {
    await disableRegisterButtonsMessage(messageId, channelId, matchId)
  }
  return response
}
```

---

## 注意事項

- Discord の `custom_id` の最大長は 100 文字。`message_id`（最大19桁）+ `channel_id`（最大19桁）+ ベース文字列で約79文字なので範囲内
- `disableRegisterButtonsMessage` の失敗は本体レスポンスに影響させないよう try/catch でラップする
