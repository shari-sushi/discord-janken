# LoL op.gg マルチサーチリンク生成 要件定義

## 概要

Discordのメンション一覧やLoLロビーログを貼り付けると、自チームメンバーを自動除外した上で
op.ggのマルチサーチURLを生成・コピー・一括オープンできるWebページ。

LTK（League Team King）等のカスタムゲームで、対戦相手チームをまとめて検索するユースケースを想定。
複数人で共有して使うため、チームデータはRedisに保存する。

## ページURL・ファイル配置

- **URL**: `/lol/opgg-multi-link`
- **ファイル**: `my-app/app/lol/opgg-multi-link/page.tsx`
- **`/lol` インデックスへの追加**: `my-app/app/lol/page.tsx` にリンクを追記

## モード構成

`/lol/role-roulette` と同様のトグルボタン（セグメントコントロール）で切り替え。

| モード | 内容 |
| --- | --- |
| **入力モード** | textareaに貼り付けて解析・除外・リンク生成 |
| **チーム検索モード** | 登録済みの相手チームを名前で検索してリンク生成 |

---

## 入力モード

### コンポーネント構成

```text
[textarea] ← ロビーログ / Discord mentions / プレーンテキストを貼り付け

[解析・除外ボタン]

--- 生き残りプレイヤーリスト ---
☑ player1   🔗
☑ player2   🔗
☐ player3   🔗  ← 個別に外したい場合にチェックを外す
...

--- op.gg URL ---
https://op.gg/ja/lol/multisearch/jp?summoners=...  [コピー]

[全タブを開く]
```

### 対応する入力形式（混在OK）

1. **ロビーログ形式**: `ROX Smeb さんが部屋に参加しました。` → `ROX Smeb` を抽出
2. **Discord形式**: `@Name#TAG` → `@` を除去して `Name#TAG` を抽出
3. **プレーンテキスト**: 1行1人のサモナー名

### チェックボックス

- 初期状態: 全員チェックON
- チェックを外すと、そのプレイヤーはURL・タブオープン対象から除外
- **チェック状態は保存しない**（ページ内のみ）

## チーム検索モード

### チーム検索モード: コンポーネント構成

```text
[チーム名を検索] ← 登録済み相手チームをインクリメンタルサーチ

--- ヒットしたチームを選択 ---
▶ チームA (5人)
▶ チームB (7人)

--- 選択後: 生き残りプレイヤーリスト（入力モードと同じUI） ---
☑ player1   🔗
☑ player2   🔗
...

https://op.gg/ja/lol/multisearch/jp?summoners=...  [コピー]

[全タブを開く]
```

---

## 共通: URL表示エリア

- op.gg マルチサーチURL をそのまま表示（URL全文が見える）
- URLの右に `[コピー]` ボタン → クリックでクリップボードにコピー
- コピー後は一瞬「コピーしました」に変化（視覚的フィードバック）
- 個別プレイヤーURL は各行の 🔗 アイコンで個別リンク

---

## 共通: 設定エリア（折りたたみ式）

ページ内に「⚙ 設定」セクション（折りたたみ式）を設け、以下を管理：

### 自チームメンバー登録

- テキストエリアまたは入力リストで自チームメンバーを登録
- **Redisに保存**（チーム全員が共有）
- 入力モードで解析時、ここのメンバーを自動除外する

### 相手チーム登録

- チーム名 + メンバーリスト（5〜8人）を登録
- **Redisに保存**（チーム全員が共有）
- チーム検索モードで使用する

---

## データ設計（Redis）

| データ | Redisキー（案） | 型 |
| --- | --- | --- |
| 自チームメンバー | `lol:opgg:self-team` | JSON: `string[]` |
| 相手チーム一覧 | `lol:opgg:enemy-teams` | JSON: `{ name: string; members: string[] }[]` |

---

## Web API（新規追加が必要）

作業前に `.claude/rules-on-demand/web-api.md` を読み込むこと。

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/web/lol/opgg/self-team` | 自チームメンバー取得 |
| PUT | `/api/web/lol/opgg/self-team` | 自チームメンバー更新 |
| GET | `/api/web/lol/opgg/enemy-teams` | 相手チーム一覧取得 |
| PUT | `/api/web/lol/opgg/enemy-teams` | 相手チーム追加・更新 |
| DELETE | `/api/web/lol/opgg/enemy-teams` | 相手チーム削除 |

認証は既存の Web API 認証方式に従う。

## 固定仕様

- リージョン: JP固定
- op.gg マルチサーチURL: `https://op.gg/ja/lol/multisearch/jp?summoners=name1,name2,...`
- 個別プレイヤーURL: `https://op.gg/ja/lol/summoners/jp/{name}`（`#` → `-` に変換）
- op.gg の iframe 埋め込み不可（CSP制限）のためリンク生成+別タブオープン方式

## UIスタイル

`/lol/role-roulette` に準拠：

- `"use client"` + Suspense ラップ
- ルート wrapper: `p-8 max-w-3xl mx-auto`
- ダークテーマ（zinc系カラーパレット）
- トグルボタン: `bg-zinc-800 p-1 rounded-lg` の中に `bg-zinc-600` でアクティブ表示
- ボタン: `bg-blue-500 hover:bg-blue-600 disabled:opacity-40 text-white font-semibold px-6 py-2 rounded`
- テキストエリア/インプット: `bg-zinc-800 border border-zinc-600 text-white rounded`

## 注意事項

- op.gg の個別プレイヤーURLで `#` → `-` 変換が正しい
- 全タブを一括オープンするとブラウザのポップアップブロッカーが発動する可能性あり → UIに許可を促す注記を添える
